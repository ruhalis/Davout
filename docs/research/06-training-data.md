# What was each Jev clone trained on?

Compiled 2026-10-02 from reports 01–05 in this scratchpad, the local clones of OpenJev and Kev, and one or more fetches of each project's primary source (model card, README, data-builder file, dataset card). Nothing was installed or run.

**Evidence grades**
- **VERIFIED**: the training data was read in code, a data-builder script or a dataset repo (by me or by the earlier report).
- **REPORTED**: stated in a README, model card or blog only.
- **NOT DISCLOSED**: the primary source does not say.

Some grades are mixed, for example "VERIFIED (code) / REPORTED (sizes)".

**Caveat on fetched pages.** Most fetches returned a model-written summary of the page, not the raw text. Dataset names below are copied from those summaries, and from raw code where code was read (OpenJev `code/data_mix.py`, Kev `kev/data.py`). Before citing an exact count, re-open the source.

**Abbreviations:** DS = dataset(s). "Jev outputs?" means Jev's own answers were used as training labels.
